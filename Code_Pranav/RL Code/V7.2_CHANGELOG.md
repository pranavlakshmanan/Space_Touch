## Overview

V7.2 is an experimental variant of V7.1 designed to test a hypothesis: **Does phase transition itself cause learning collapse?**

By keeping the agent in Phase 1 for the entire 200K steps, we can determine if:
1. Overlap continues improving beyond 60cm³ without phase transition
2. The Phase 1 reward balance (Proximity=50, Overlap=20) is sufficient for learning envelopment
3. Phase 2's reward changes (removing proximity) are the root cause of collapse

## Hypothesis Being Tested

### **Hypothesis:**
Phase transition to Phase 2 (removing proximity reward) causes catastrophic forgetting, not insufficient training time in Phase 1.

### **Prediction:**
If hypothesis is TRUE:
- Overlap will continue increasing beyond 60cm³ in Phase 1
- Agent will learn envelopment while maintaining proximity
- Final mean overlap at 200K will be >80cm³

If hypothesis is FALSE:
- Overlap will plateau at ~60cm³ even without phase transition
- Phase 1 reward balance insufficient for envelopment learning
- We need more sophisticated reward shaping, not just phase timing

## Expected Outcomes

### Scenario 1: Hypothesis Confirmed (60% probability)
**Observation:** Overlap continues improving in Phase 1, reaches >80cm³
**Conclusion:** Phase 2 transition was the problem
**Next Steps:** Design "Phase 1.5" (gentle transition) or skip Phase 2 entirely

### Scenario 2: Hypothesis Rejected (30% probability)
**Observation:** Overlap plateaus at ~60cm³ even in Phase 1
**Conclusion:** Phase 1 reward balance insufficient for envelopment
**Next Steps:**
- Increase overlap weight in Phase 1 (20 → 40)
- Add shaped overlap reward (distance-based multiplier)
- Introduce intermediate reward milestones

### Scenario 3: Different Issue Revealed (10% probability)
**Observation:** Unexpected behavior (e.g., distance increases, contacts increase)
**Conclusion:** Other issues at play (hull calculation bug, environment issue)
**Next Steps:** Deep dive debugging
