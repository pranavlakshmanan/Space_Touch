## Overview

V7.3 represents a **fundamental paradigm shift** from all previous versions (V2-V7.2). Instead of rewarding absolute states (overlap volume, proximity), V7.3 rewards **CHANGE** in overlap.

### The Core Problem (V2-V7.2)

All previous versions suffered from **learning collapse**:
- Agent learns initial approach → achieves 60-120cm³ overlap
- Performance plateaus or regresses over time
- Phase transitions cause catastrophic forgetting
- Local optima trap: "good enough" is actually rewarded

**Root cause:** Rewarding absolute state allows the agent to rest at comfortable configurations with no incentive to improve.

### The V7.3 Solution

**Reward improvement, penalize regression, give zero for plateau:**

```python
delta_overlap = current_overlap - previous_overlap

if delta_overlap > 0:
    reward = delta_overlap * 50000  # Improvement rewarded
elif delta_overlap < 0:
    reward = delta_overlap * 50000 * 1.5  # Regression penalized MORE
else:
    reward = 0  # Plateau gets nothing - must keep improving!
```

This creates:
- **No local optima:** Can't rest at "good enough"
- **No reward hacking:** Oscillating (close-far-close) nets zero over time
- **Automatic curriculum:** Agent naturally progresses from approach → overlap → refinement
- **Skill retention:** Regression is costly, prevents forgetting

## Key Innovations

### 1. **Derivative Reward (Primary Innovation)** 🚀

**What changed:**
- V2-V7: `reward = f(absolute_overlap)`
- V7.3: `reward = f(delta_overlap) = f(current - previous)`

**Parameters:**
- `improvement_scale`: 50,000 (scales tiny m³ changes to meaningful rewards)
- `regression_multiplier`: 1.5 (regression hurts 50% more than improvement helps)

**Impact:**
- Eliminates plateaus completely
- Forces continuous improvement
- Prevents oscillation strategies

---

### 2. **Sustain Bonus** 🎯

**Purpose:** Small reward for maintaining high overlap (prevents thrashing)

**Implementation:**
```python
if current_overlap > 50cm³:
    reward += 2.0
```

**Parameters:**
- `sustain_threshold`: 0.00005 m³ (50cm³)
- `sustain_bonus`: 2.0

**Impact:**
- Encourages stability once high overlap achieved
- Balances improvement drive with maintenance
- Prevents constant searching behavior

---

### 3. **Bootstrap Proximity Guide** 🗺️

**Purpose:** Help agent discover target in first 30K steps

**Implementation:**
```python
if total_steps < 30000 and overlap ≈ 0:
    proximity_reward = 5.0 * (1/distance - 1/0.5)
```

**Parameters:**
- `bootstrap_steps`: 30,000
- `bootstrap_proximity_scale`: 5.0

**Key features:**
- **ONLY** active when overlap is zero (no interference with overlap learning)
- **ONLY** active first 30K steps (training wheels come off)
- Weak signal (5.0 max) compared to overlap improvement (can be 100+)

**Impact:**
- Helps agent find target initially
- Automatically disabled once overlap learning begins
- Doesn't create dependence or interfere with main objective

---

### 4. **Distance-Scaled Contact Penalty** 📏

**Purpose:** Natural curriculum for contact avoidance

**Implementation:**
```python
distance_factor = clip(1.0 - (distance / 0.25), 0.0, 1.0)
penalty_per_finger = -1.0 + (-4.0 * distance_factor)
# Range: -1 (far) to -5 (close)
```

**Parameters:**
- `contact_penalty_min`: -1.0 (when >0.25m away)
- `contact_penalty_max`: -5.0 (when <0.05m away)
- `contact_distance_scale`: 0.25m

**Examples:**
- **0.30m away:** Contact penalty = -1 per finger (gentle, exploring)
- **0.15m away:** Contact penalty = -2.6 per finger (learning precision)
- **0.05m away:** Contact penalty = -4.2 per finger (must be precise)
- **Touching (0m):** Contact penalty = -5 per finger (harsh deterrent)

**Impact:**
- Early training: Agent can explore with light contact
- Mid training: Increasing pressure to avoid contact
- Late training: Strong deterrent for precision
- Natural skill progression without manual phase changes

## What Was Removed

### ❌ **All Phases/Curriculum** (V7.0-V7.2)
- No Phase 0, 1, 2, 3
- No phase transitions
- No phase-specific reward weights
- No curriculum callback

**Rationale:** Derivative reward creates natural curriculum through task structure

### ❌ **Absolute State Rewards**
- No proximity reward (except tiny bootstrap guide)
- No absolute overlap reward
- No quality/clearance rewards

**Rationale:** Rewarding change, not state

### ❌ **Phase-Dependent Starting Positions**
- Fixed 10cm starting distance throughout training

**Rationale:** No phases = no need for curriculum

## Theoretical Foundation

### Why Derivative Rewards Work

**1. Eliminates Local Optima:**
- Absolute reward: `R = f(state)` has maxima where `dR/dstate = 0`
- Derivative reward: `R = state' = dstate/dt` → Only maximum when state→∞
- Agent must continuously improve to get non-zero reward

**2. Natural Curriculum:**
- Early: Large improvement possible → Large positive rewards
- Mid: Moderate improvement → Moderate rewards
- Late: Small improvement → Small rewards (but still positive!)
- This matches difficulty progression without manual phasing

**3. Prevents Reward Hacking:**
- Oscillation strategy (improve → regress → improve):
  - Step 1: +X reward (improvement)
  - Step 2: -1.5X reward (regression, asymmetric)
  - Net: -0.5X (punished!)
- Agent learns stable improvement only viable strategy

**4. Continuous Pressure:**
- Zero reward for plateau creates perpetual search
- Sustain bonus prevents thrashing
- Balance between "keep improving" and "don't break what works"

### Comparison to Other RL Approaches

**Curiosity/Intrinsic Motivation:**
- Similar: Rewards novelty/change
- Different: V7.3 rewards *specific* change (overlap improvement)

**Reward Shaping:**
- Similar: Guides learning with intermediate rewards
- Different: V7.3 shape emerges from derivative, not hand-crafted

**Curriculum Learning:**
- Similar: Progressive difficulty
- Different: V7.3 curriculum automatic, not staged

## Code Organization

### V7.3 Reward Calculator (`v7_3_reward.py`)

**Key Methods:**
- `calculate_reward()`: Main reward computation
  - Computes delta_overlap
  - Applies asymmetric scaling
  - Adds sustain bonus
  - Checks bootstrap stage
  - Scales contact penalty by distance

- `reset()`: Episode reset
  - **Critical:** Sets `previous_overlap = 0` to avoid artificial penalty
  - Resets cache but not step_counter

- `update_phase()`: No-op (compatibility with environment)

**Key State Variables:**
- `previous_overlap`: Stored overlap from last step (for delta)
- `total_steps`: Global counter (for bootstrap stage)
- `step_counter`: Local counter (for hull computation frequency)

### V7.3 Environment (`v7_3_sc1.py`)

**Key Changes from V7:**
- Uses `V73RewardCalculator`
- Fixed starting position (no phase-dependent spawning)
- `update_phase()` is no-op
- Removed curriculum callback from training

**Unchanged from V7:**
- Environment dynamics
- Observation/action spaces
- Direct position control
- Memory optimizations
