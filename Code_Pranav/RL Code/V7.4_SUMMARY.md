## Key Changes from V7.3

### 1. Observation Space: 28D → 32D ✨

**New observations added:**
- **obs[28]:** Smoothed overlap volume (EMA, 1D)
  - Normalized to 0-1 range
  - Reduces noise from raw hull computation

- **obs[29:32]:** Relative distance vector (3D)
  - `target_pos - hand_center`
  - Direct navigation signal
  - Agent knows which direction to move

### 2. Reward Function: Pure Derivative → Hybrid 🎯

**V7.3 (Failed):**
```python
reward = delta_overlap * 50000
# Result: Agent wanders, distance increases
```

**V7.4 (90:10 ratio):**
```python
# PRIMARY: Derivative overlap (±100 reward)
reward = delta_overlap * 50000

# SECONDARY: Distance reward (0-10 reward)
reward += 10.0 * exp(-2.0 * distance)
```

**V7.4.1 (80:20 ratio):**
```python
# PRIMARY: Derivative overlap (±100 reward)
reward = delta_overlap * 50000

# SECONDARY: Distance reward (0-20 reward)
reward += 20.0 * exp(-2.0 * distance)
```

**Rationale:**
- Distance reward provides navigation compass
- Derivative prevents plateaus
- 90:10 is more "pure", 80:20 has more guidance

### 3. Removed Bootstrap Proximity
- V7.3 had bootstrap_proximity_scale parameter
- V7.4/V7.4.1: Removed (distance reward replaces it)

## WandB Metrics to Monitor

### New V7.4 Metrics (vs V7.3)
- `reward/distance` - Distance reward component (0-10 or 0-20)
- `hull/delta_overlap_cm3` - Still tracked
- Observation space dimension shown as 32D in config

### Key Success Indicators

**✅ Good Training (What to Look For):**
1. `stats/mean_distance` **DECREASING** over time (0.35m → 0.15m)
2. `stats/mean_overlap_cm3` **INCREASING** over time (10 → 80+cm³)
3. `hull/delta_overlap_cm3` mostly positive (agent improving)
4. `reward/distance` non-zero but small (guide, not dominant)
5. `state/contacts` decreasing

**❌ Bad Training (Warning Signs):**
1. `stats/mean_distance` increasing (agent wandering away)
2. `stats/mean_overlap_cm3` oscillating or declining
3. `hull/hand_volume_cm3` wild oscillations (600-1400cm³)
4. `reward/distance` dominates total reward (distance too strong)

## Troubleshooting

### Issue: Distance Still Increasing

**Symptoms:**
- `stats/mean_distance` going up even with distance reward
- Agent wandering away from target

**Solutions:**
1. Increase distance_reward_scale (10 → 15 for V7.4, 20 → 30 for V7.4.1)
2. Check relative distance vector in observation (obs[29:32])
3. Verify hand_center calculation is correct

### Issue: Overlap Not Improving

**Symptoms:**
- `stats/mean_overlap_cm3` stuck at 20-30cm³
- `hull/delta_overlap_cm3` mostly negative or zero

**Solutions:**
1. Check smoothed overlap in observation (obs[28])
2. Increase improvement_scale (50K → 75K)
3. Check if hand volume is stable (should be 600-800cm³)

### Issue: Too Many Contacts

**Symptoms:**
- `state/contacts` high (>20% of steps)
- `reward/contact_penalty` large and negative

**Solutions:**
1. Contact penalty is distance-scaled (-1 to -5)
2. Should naturally reduce as agent learns
3. If persistent, might increase contact_penalty_max (-5 → -7)
