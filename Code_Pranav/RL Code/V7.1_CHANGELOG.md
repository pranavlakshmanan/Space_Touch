## Overview

V7.1 addresses the Phase 2 learning collapse observed in V7 training runs. The core issue was that removing proximity reward entirely in Phase 2 caused the agent to "forget" navigation and wander randomly, resulting in sparse overlap feedback and declining performance.

**Key Philosophy:** Balance skill isolation with skill retention. Phase 2 still focuses on overlap (50:1 ratio) but maintains a small proximity baseline to prevent catastrophic forgetting.

---

## Critical Changes (High Impact)

### 1. **Proximity Baseline in Phase 2** 🎯 MOST IMPORTANT
- **File:** `reward_functions/v7_reward.py:96`
- **Change:** `proximity_weight: 0.0 → 10.0`
- **Ratio:** Overlap:Proximity = 500:10 = 50:1
- **Impact:** Agent maintains distance awareness while still heavily prioritizing overlap
- **Expected:** Eliminates wandering, provides stable navigation baseline

### 2. **Adaptive Learning Rate** 🧠
- **File:** `Code_Pranav/RL Code/v7_sc1.py:708-712`
- **Change:** Phase 0-1: `3e-4`, Phase 2+: `1e-4` (3x reduction)
- **Impact:** Slower learning in Phase 2 prevents catastrophic forgetting of Phase 1 navigation skills
- **Mechanism:** Automatically reduces LR when transitioning to Phase 2
- **Logging:** LR changes logged to WandB as `hyperparameters/learning_rate`

### 3. **Extended Phase 2 Duration** ⏱️
- **File:** `Code_Pranav/RL Code/v7_sc1.py:620-621`
- **Change:**
  - Min steps: `60K → 80K`
  - Max steps: `70K → 90K`
  - Total Phase 2: Now runs for 90K steps (total: 180K)
- **New timeline:** Phase 0(30K) → Phase 1(60K) → Phase 2(90K) → Phase 3(20K)
- **Impact:** More time for the hardest phase (envelopment learning)

## Reward Function Changes

### 4. **Strengthened Contact Penalties** 💥
- **File:** `reward_functions/v7_reward.py:89, 98`
- **Changes:**
  - Phase 1: `-2.0 → -5.0` (2.5x increase)
  - Phase 2: `-5.0 → -10.0` (2x increase)
  - Phase 3: `-20.0` (unchanged)
- **Impact:** Progressive deterrent - reduces collision frequency
- **Risk:** Monitor that agent doesn't learn "stay away" instead of "approach carefully"

### 5. **Quality Reward Boost** ✨ (Optional)
- **File:** `reward_functions/v7_reward.py:99`
- **Change:** Phase 2 `quality_weight: 3.0 → 5.0`
- **Impact:** Stabilizes hand configuration, prevents finger collapse
- **Rationale:** Addresses 3.5x hand volume variance (400-1400 cm³)
- **Note:** Marked as optional in code - can revert to 3.0 if causes issues

### 6. **Overlap Reward Scaling** 📈 (Optional)
- **File:** `reward_functions/v7_reward.py:354`
- **Change:** `tanh(overlap_cm3 / 50.0) → tanh(overlap_cm3 / 75.0)`
- **Impact:** Delays saturation, provides more learning gradient for larger overlaps
- **Note:** Marked as optional - can revert to 50.0 if needed

## Environment & Hyperparameter Changes

### 7. **Tighter Distance Termination** 🎯
- **File:** `Code_Pranav/RL Code/v7_sc1.py:446`
- **Change:** `0.25m → 0.20m`
- **Impact:** Forces agent to stay closer to target, reduces wasted exploration
- **Risk:** May increase early terminations - monitor episode lengths

### 8. **Increased Hull Computation Frequency** ⚡
- **File:** `Code_Pranav/RL Code/v7_sc1.py:164`
- **Change:** `24 steps (10Hz) → 12 steps (20Hz)`
- **Impact:** 2x more frequent feedback = faster learning
- **Risk:** 2x computation cost - monitor RAM usage and training speed
- **Mitigation:** V6 memory fixes should handle this

### 9. **Increased Exploration** 🔍
- **File:** `Code_Pranav/RL Code/v7_sc1.py:797`
- **Change:** `ent_coef: 0.001 → 0.005` (5x increase)
- **Impact:** More exploration in Phase 2's hard search space
- **Monitor:** Ensure entropy stays >0.5 in logs

### 10. **Increased Rollout Buffer** 📊
- **File:** `Code_Pranav/RL Code/v7_sc1.py:791`
- **Change:** `n_steps: 2048 → 4096` (2x increase)
- **Impact:** More stable learning, collects more experience before policy update
- **Trade-off:** Slightly slower updates (agent sees older data)
- **Risk:** Memory usage increases ~400KB - should be manageable
