## Dual Curriculum Learning System

### **Reward Curriculum (5 Phases)**
Progressive complexity introduction based on training timesteps:

1. **Phase 1 (0-40K):** Distance reward only
   - `reward = exp(-6.0 * distance_to_target)`
   - Focus: Basic reaching behavior

2. **Phase 2 (40K-80K):** + Tendon efficiency
   - `efficiency_reward = 0.15 * (1.0 - 0.4 * mean_tendon_force)`
   - Focus: Energy-efficient movement

3. **Phase 3 (80K-120K):** + Tactile contact (when close)
   - `tactile_reward = 0.1 * num_active_fingers` (if distance < 0.15m)
   - Focus: Contact-based feedback

4. **Phase 4 (120K-160K):** + Movement penalty
   - `movement_penalty = -0.005 * (linear_vel + angular_vel)`
   - Focus: Smooth, controlled movement

5. **Phase 5 (160K-200K):** + Hand shape reward
   - `shape_reward = 0.05 * (spread_reward + compactness_reward)`
   - Focus: Optimal grasping configuration

### **Target Curriculum (3 Phases)**
Progressive target complexity:

1. **Phase 1 (0-160K):** Static targets at fixed position
2. **Phase 2 (160K-180K):** Slow moving targets (0.01 m/s)
3. **Phase 3 (180K-200K):** Dynamic targets (random movement)

## Technical Implementation Details

### **Hand Shape Metrics (Replaces Convex Hull)**
```python
def _compute_hand_shape_features(self, finger_positions):
    points = finger_positions.reshape(4, 3)

    # Hand spread: maximum distance between any two fingers
    distances = [np.linalg.norm(points[i] - points[j])
                for i in range(len(points))
                for j in range(i+1, len(points))]
    hand_spread = np.max(distances)

    # Compactness: average distance from fingers to hand center
    center = np.mean(points, axis=0)
    compactness = np.mean([np.linalg.norm(point - center) for point in points])

    return hand_spread, compactness
```

### **Reward Function Architecture**
```python
def _compute_improved_reward(self, base_pos, target_pos, tendon_forces,
                           binary_tactile, base_vel, hand_spread, hand_compactness):
    distance = np.linalg.norm(base_pos - target_pos)

    # Component 1: Distance (Phase 1+)
    distance_reward = np.exp(-6.0 * distance) if self.reward_curriculum_phase >= 1 else 0.0

    # Component 2: Tendon Efficiency (Phase 2+)
    tendon_efficiency_reward = (0.15 * (1.0 - 0.4 * np.mean(tendon_forces))
                               if self.reward_curriculum_phase >= 2 else 0.0)

    # Component 3: Tactile Contact (Phase 3+, when close)
    tactile_contact_reward = (0.1 * np.sum(binary_tactile)
                             if self.reward_curriculum_phase >= 3 and distance < 0.15 else 0.0)

    # Component 4: Movement Penalty (Phase 4+)
    movement_penalty = (-0.005 * (np.linalg.norm(base_vel[:3]) + np.linalg.norm(base_vel[3:]))
                       if self.reward_curriculum_phase >= 4 else 0.0)

    # Component 5: Hand Shape (Phase 5+)
    if self.reward_curriculum_phase >= 5:
        target_spread, target_compactness = 0.12, 0.06
        spread_reward = np.exp(-abs(hand_spread - target_spread) * 10)
        compactness_reward = np.exp(-abs(hand_compactness - target_compactness) * 15)
        hand_shape_reward = 0.05 * (spread_reward + compactness_reward)
    else:
        hand_shape_reward = 0.0

    # Success bonus
    success_bonus = 8.0 if (distance < 0.08 and np.sum(binary_tactile) >= 2) else 0.0

    return {
        'total_reward': sum([distance_reward, tendon_efficiency_reward, tactile_contact_reward,
                           movement_penalty, hand_shape_reward, success_bonus]),
        'distance_reward': distance_reward,
        'tendon_efficiency_reward': tendon_efficiency_reward,
        'tactile_contact_reward': tactile_contact_reward,
        'movement_penalty': movement_penalty,
        'hand_shape_reward': hand_shape_reward,
        'success_bonus': success_bonus
    }
```

### **Fixed WandB Logging System**
```python
class FixedWandBCallback(BaseCallback):
    def _safe_wandb_log(self, log_dict, step=None):
        """Safely log to WandB with error handling and conflict prevention"""
        try:
            if step is None:
                # Let WandB auto-increment steps (FIXED approach)
                wandb.log(log_dict)
            else:
                # Only use explicit step if it's greater than last logged step
                if step > self.last_logged_step:
                    wandb.log(log_dict, step=step)
                    self.last_logged_step = step
                else:
                    # Fall back to auto-increment
                    wandb.log(log_dict)
        except Exception as e:
            if self.verbose > 0:
                print(f"WandB logging error: {e}")
```

**Key Fixes:**
- Removed explicit step parameters from most wandb.log() calls
- Added last_logged_step tracking to prevent duplicates
- Disabled sync_tensorboard=False to avoid SB3/WandB conflicts
- Safe error handling with fallback mechanisms
